⚙️ Settings additive — no recorder logic touched

All toggles below are non-intrusive: they affect new runs only, never an in-progress recording.

🧠 Local AI Engine

Powered by a locally-running Ollama daemon. No data leaves your machine. When enabled, AI suggests replacement selectors when the recorder's primary + fallback chain fails. Disabling it falls back to the deterministic healer only — every existing test continues to work.

Enable local AI
Toggles the AI suggest-locator endpoint. The deterministic healer always runs first; AI only fires when ALL recorded fallbacks are exhausted.

🤖 AI Assistant (Ollama)

Cursor-style chat for fixing test code, locally. Toggle the panel anywhere with Ctrl+Shift+A. Backed by your own Ollama daemon — no data leaves the machine, no API key required.

Enable AI Assistant panel
When on, a floating panel is available on Recording, Dashboard and Settings tabs.

📧 Email reports

Send rerun reports and dashboard summaries by email. Powered by SMTP — works with Gmail (app password), Outlook/Office 365, corporate Exchange, internal Postfix relays, etc. Credentials live only on this server in config/email.json (gitignored, file mode 0600). The dashboard never sees the password.

🧩 Default framework

The default framework picked when you start a new project from the recorder. Each registered framework has a generator plugin under generators/; see PLUGIN.md to add a new one.

Default framework
Stored in your browser only (localStorage). The recorder reads this when it boots.

📸 Capture defaults

Controls whether failure screenshots and full-run videos are captured during reruns. Settings persist per browser (localStorage). Each rerun can still override these with the toggles in the Recording panel.

Capture failure screenshots
When a step fails the rerun engine takes a PNG and saves it to <rerunDir>/screenshots/step-N-failed.png. Generated framework hooks (Cucumber / TestNG @After) attach the same to Allure / HTML reports. Recommended: ON.
Record video on rerun
Adds recordVideo to the rerun's Playwright context. Each scenario is saved as a .webm under videos/. Off by default — videos make reruns ~2× slower and consume disk space.

🖥 Server

Live process serving this UI. Read-only.

Settings live per browser via localStorage (default framework) and per server process via runtime calls to /api/ai/toggle (AI on/off). Nothing here writes to disk in your repo. Your existing recordings, generated projects, and rerun reports are untouched.
